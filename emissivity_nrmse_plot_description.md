
The plot above explores how potential bias in emissivity values results in changes in estimated FRPD error. 

In this sensitivity analysis we apply a uniform bias to all spectral emissivity values (from -20% to +20%) and explore how nRMSE changes while theoretical FRPD remains unchanged, as assumed allwave emissivity does not change. Spectral emissivity ranges selected for $\varepsilon_{1, \lambda}$ and $\varepsilon_{2, \lambda}$ may not accurately represent actual spectral emissivity ranges, so this analysis simulates how the models behave when the assumed spectral emissivity varies from the actual  spectral emissivity. The coefficients determining the best fit relationship (Eq. 6) are determined once in the `Radiance vs. FRPD` plot and reused as spectral emissivity varies according to the applied percent bias.
